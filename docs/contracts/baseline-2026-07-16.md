# Comment/Interaction baseline — 2026-07-16

- Both modules compiled with only `contextLoads()` tests.
- Comment create accepted `userId` in JSON; delete accepted it as a query parameter.
- Comment had create/list/delete only; no target/parent validation, edit or pagination.
- Interaction create accepted `userId` in JSON and caught every `DataIntegrityViolationException` as duplicate.
- Interaction had no remove/current-reaction/counter endpoints.
- Interaction included `BOOKMARK` despite Post owning bookmark persistence.
- Both modules used UUID entities and PostgreSQL with Hibernate `ddl-auto=update`.
